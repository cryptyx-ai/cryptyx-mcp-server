# CRYPTYX skills

The CRYPTYX skills now ship in one place, the agent plugin: https://github.com/cryptyx-ai/agents

They are written for the same tools this package serves, and are maintained with them. Install the plugin in
Claude Code, Grok Build or another agent host, or copy a skill's `SKILL.md` into any client that loads skills.

Earlier versions of this package bundled four skills here. They were built around tools the CRYPTYX connector no
longer carries, so they were removed in 0.12.0 rather than left pointing at tools that refuse.
